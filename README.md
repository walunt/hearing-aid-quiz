# 助听器验配师（三级）考试复习系统

单文件离线 HTML 刷题系统，无需安装、无需联网、浏览器直接打开即用。

## 📱 在线使用

手机/电脑浏览器打开 GitHub Pages 地址即可刷题，做题进度自动保存在浏览器本地：

**https://walunt.github.io/hearing-aid-quiz/**

## ✨ 功能

- **363 道题**：221 道单选 + 142 道多选，内置全部解析与考察点
- **四种刷题模式**：混合随机 / 仅单选 / 仅多选 / 只刷未做题
- **薄弱突击**：间隔重复算法，错题更高频复现，越难越常出
- **错题本**：答错自动收录，答对自动移出
- **分类练习**：按知识点（耳部解剖、声学基础、测听方法、声导抗、儿童康复、助听器技术、职业道德等）逐个击破
- **相似题对比**：13 组易混对比 + 表述变体 + 纯记忆题（年份/缩写代号）专项
- **速记手册**：蒙题策略 + 知识点速览
- **轮次进度**：刷满全部 363 题算一轮，自动进入下一轮重新计数
- **主题切换**：亮/暗色模式

## 🛠 本地构建（可选）

系统由题库 docx 一键生成，源码在此仓库中：

```bash
python build_html.py
```

生成 `验配师考试复习系统.html` / `index.html`。

## 📝 说明

- 题目与答案以题库原题为准，知识点解析为辅助学习材料
- 学习进度（做题记录、错题本、轮次）保存在浏览器 localStorage，清除浏览器数据会重置
